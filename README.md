# TMO: Thresholding Multiple Outcomes

Version 1.0.0. TMO estimates standard errors using auxiliary outcomes to measure correlation across locations.

## Installation

Run in Stata:

    net install tmo, from("https://raw.githubusercontent.com/wjnkim/tmo/main/src") replace
    help tmo

## Reference

DellaVigna, Stefano, Guido Imbens, Woojin Kim, and David Ritzwoller. (2026). "Using Multiple Outcomes to Adjust Standard Errors for Spatial Correlation." [https://arxiv.org/pdf/2504.13295](https://arxiv.org/pdf/2504.13295)
